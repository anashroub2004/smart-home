## ما الذي تغيّر
- **الـ Pi صار جهاز تطوير للـ ESP32 أيضاً:** يبني الكود ويرفعه للوحة بكابل USB مباشرة، والـ broker على نفس الجهاز.
- **ثُبّت على الـ Pi (Ubuntu 26.04، ARM64):**

| الأداة | الإصدار | من أين | ملاحظة |
|---|---|---|---|
| `gh` (GitHub CLI) | 2.105.0 | مستودع GitHub الرسمي (`cli.github.com/packages`) | مسجّل الدخول بحساب `anashroub2004` (ADMIN على المستودع) |
| PlatformIO Core | 6.2.0 | السكربت الرسمي `get-platformio.py` ← `~/.platformio/penv` | الأمر `pio` في `~/.local/bin` |
| منصة `espressif32` | 8.0.0 | PlatformIO | **فيها Arduino core 3.3**، فلا حاجة لـ `pioarduino` |
| VS Code | 1.147.0 | مستودع Microsoft (`packages.microsoft.com/repos/code`) | إضافة PlatformIO IDE 3.3.4 + C/C++ 1.35.6 |
| صلاحيات USB | — | `99-platformio-udev.rules` + مجموعة `dialout` | تعمل بعد الخروج والدخول للحساب |

- **اختبار بناء:** مشروع تجربة لـ `esp32dev` بنفس مكتبات `esp_a_test` (PubSubClient، DHT sensor library، ESP32Servo، WiFi):
  **SUCCESS**، RAM 6.9%، Flash 21.3%. أول بناء 11 دقيقة (تنزيل نحو 4.5 GB من أدوات Espressif على شبكة بطيئة)، وبعده ثوانٍ.
- كل هذا منفصل عن بيئة الخدمات في `/opt/smart-home/.venv`، ولا يؤثر على البيت.

## ما يجب تنفيذه بعد هذا التحديث
- `git checkout main` ← `git pull`. لا Hosting ولا Rules ولا `install.sh`.

## قرارات جديدة (تُنسخ أيضاً إلى PROJECT_CONTEXT.md)
- **اقتراح (ينتظر موافقة إياد، صاحب `firmware/`):** الـ firmware النهائي مشروع **PlatformIO** واحد في `firmware/`
  فيه بيئة لكل عقدة (`[env:bedroom]`، `[env:living]`)، وإصدارات المكتبات مثبّتة في `platformio.ini`، و`secrets.h` خارج Git،
  وبناء في CI مثل اختبارات الـ Pi. Arduino IDE يبقى للتجارب السريعة مثل `esp_a_test`.

## ملاحظات تفيد من يكرر التثبيت
- **`snap install code` لا يعمل على الـ Pi** (الـ snap لـ amd64 فقط). استعمل مستودع Microsoft بـ `apt`.
- **`arduino` من `apt`/snap هو IDE 1.8 القديم.** إن احتجتم Arduino على الـ Pi: `arduino-cli` (يدعم ARM64).
- **إن لم يظهر `/dev/ttyUSB0` عند توصيل لوحة بشريحة CH340:** برنامج `brltty` في Ubuntu يخطف المنفذ ← `sudo apt remove brltty`.
- **الكهرباء:** الـ ESP32 وحده من USB الـ Pi لا مشكلة. السيرفو والـ LD2410C من مصدر 5V منفصل (GND مشترك)، لأن الـ Pi
  أعطى تحذير جهد منخفض سابقاً.
- **Mosquitto حذّر أثناء `install.sh`:** ملف `/etc/mosquitto/smart-home.passwd` مالكه `mosquitto` لا `root`
  (`install.sh` سطر 72). تحذير فقط الآن، لكن إصدارات قادمة قد ترفض الملف. يحتاج تعديلاً لاحقاً في `install.sh`.
