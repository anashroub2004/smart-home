## لماذا
آخر خطوة في قائمة "ما قبل الـ Pi": كل التجارب السابقة كانت على Firebase المحلي (الـ emulator). هنا شغّلنا **الخدمات الأربع + العقد الوهمية (عالم أحمد بالوقت الحقيقي)** على المشروع الحقيقي **`ai-home-aef50`** حوالي 20 دقيقة (19:10 – 19:30). وإياد استعمل **التطبيق الحقيقي** https://ai-home-aef50.web.app.

## ما وُجد وأُصلح
- **Avast يفحص HTTPS على حاسوب إياد:** يضع شهادته ("Avast Web/Mail Shield Root") بدل شهادة Google.
  - Windows والمتصفح يثقان بها، لكن Python يرفض الاتصال (`CERTIFICATE_VERIFY_FAILED`). هذا نفس سبب حاجة git إلى `schannel`.
  - **الحل (موافقة إياد):** `pip install truststore`، وسطران في `pi/cloud_db.py` يستعملانه إن وُجد، فيثق Python بما يثق به Windows.
  - **اختياري: ليس في `requirements.txt`**، والـ Pi لا يحتاجه.
