## النتائج (بوابة 1a: نجحت)

بـ `mosquitto_sub -t "home/#" -v`:
- كل عقدة `online`، وحالة كل أجهزتها، وكل الحساسات الموجودة في `seed.json` فقط.
  - المدخل لا يرسل PIR، لأن PIR الخارجي على الـ Pi (GPIO17).
- `set` للضوء ← `state {"v":1}` + `power {"w":1.2}`. المروحة level 100 ← `power {"w":2.4}`. ضوء المطبخ عبر `living` ✅.
- `press bedroom_light` ← `{"v":0,"src":"button"}`. و`lux` غرفة النوم 370 ← 520 ← 370 مع الضوء.
- `finger 2` ← `door/event` + القفل `v:1` ثم `v:0` بعد 5 ثوانٍ. `pin wrong` ← `ok:false` بلا فتح. `home/door/open` ← يفتح.
- `unplug living` ← **Mosquitto أرسل `home/living/status offline` وحده** (LWT). `plug living` ← `online` + الحالة كاملة.
- `--broken bathroom/temp` ← لا تُرسل أبداً.
- **config v3** (أضيف `lux` للحمام، وحُذفت مروحة النوم):
  - `config/ack {"version":3}`.
  - `bathroom/lux 0` بدأ يُرسل.
  - أوامر المروحة المحذوفة تُتجاهل.
