# ملف الروتين — الشخص الذي يعيش في الاستوديو

`student_studio.toml` يصف **طالباً جامعياً يعيش وحده في استوديو**. منه يأتي شيئان:

- **تاريخ التدريب:** `ai/lifesim.py` يولّد منه أسابيع أو سنة من القراءات، كما لو كان الـ Pi يسجّل في بيت حقيقي.
- **الشخص الحي في التوأم الرقمي:** `pi/person.py` يعيش نفس الأيام بالضبط.

لذلك ما يتعلمه النموذج وما تراه في التوأم شيء واحد.

## الطبقات الثلاث

| الطبقة | أمثلة من الملف |
|---|---|
| **ثابتة** | الاستيقاظ قبل الخروج بـ ~55 دقيقة، الحمام ثم الفطور، الطبخ، الدراسة، القراءة في السرير ثم النوم |
| **متغيرة** | جدول أسبوعي يختلف كل يوم (أحد/ثلاثاء/خميس 7:35، إثنين/أربعاء 9:40، النادي، سهرة الخميس، زيارة الأهل الجمعة)، فصول دراسية، امتحانات (دراسة وسهر)، عطلة، عمل صيفي، رمضان (سحور، إفطار عند الغروب، سهر)، العيد، رحلات، الطقس والغروب حسب التاريخ، النوم يتأخر تدريجياً خلال الفصل |
| **شاذة** | مرض، أرق، ضيوف، نوم بلا منبّه، سهرة متأخرة، سهر حتى الفجر في الامتحانات، انقطاع كهرباء، باب ثلاجة مفتوح، موجة حر، النوم والضوء مضيء |

**الأوامر اليدوية:**

- **الضوء:** يشعله في الظلام عادةً، وكثيراً ما ينساه عند الخروج.
- **المروحة:** يشغّلها عندما يتجاوز "حرّه الشخصي" (يختلف قليلاً كل يوم).
- **الشفّاطات:** شفّاط المطبخ أثناء الطبخ، وشفّاط الحمام بعد الاستحمام، وأحياناً ينساهما.
- **الغسيل:** يوم السبت عادةً.
- **التطبيق:** يشغّل المروحة منه قبل الوصول في الأيام الحارة.

كل ضغطة تُسجَّل `override/<device>` كما يفعل الـ Pi.

## التعديل والتجربة

1. **عدّل الملف:** القيم موثّقة داخله. مثال: `oversleep = 0.07` تعني 7% من الأيام.
2. **ولّد البيانات:**
   ```powershell
   python -m ai.lifesim --days 365
   ```
   - **المدة:** حوالي 40 ثانية.
   - **قاعدة البيانات:** `ai/data/persona_year.db`، حوالي 1.6 مليون قراءة.
   - **اليوميات:** `ai/data/persona_year.diary.csv`، سطر لكل يوم: نوعه، أحداثه، الاستيقاظ والنوم، الأوامر اليدوية، الطاقة.
   - **الملخص:** `ai/data/persona_year.summary.json`، فيه مقدار اختلاف الأيام.
3. **قيّم النموذج:**
   ```powershell
   python -m ai.experiment_year
   ```
   - **المدة:** حوالي 5 دقائق.
   - **النتيجة:** `ai/reports/year_evaluation.md` مع رسم `.svg`.
   - **الطريقة:** لكل أسبوع يتدرب النموذج على الأسابيع التي قبله فقط، ثم يُختبر على أسبوع لم يره.
4. **التوأم:**
   ```powershell
   python pi/sim_house.py --twin-only --speed 60
   ```
   - **الروتين:** يستخدم هذا الملف تلقائياً. `--persona none` يرجع للروتين القديم، و`--persona ملف_آخر.toml` لشخصية أخرى.
   - **تاريخ التوأم القديم:** إذا كان عندك تاريخ توأم قديم احذف `ai/data/twin.db*` و`ai/models/twin/` ليبدأ من الشخص الجديد.

## شخصية جديدة

انسخ الملف بإسم جديد، مثلاً `employee_studio.toml`، وغيّر الجدول والاحتمالات، ثم:

```powershell
python -m ai.lifesim --days 365 --persona ai/personas/employee_studio.toml --out ai/data/employee.db
python -m ai.experiment_year --db ai/data/employee.db --name employee_year
```

## ملاحظات صادقة للتقرير

- **كل الأرقام من بيانات محاكاة،** ويجب ذكر ذلك.
- **قيم الواط بمقياس المجسّم** (مصباح 1.2 واط، مروحة 2.4 واط)، لا بمقياس البيت الحقيقي.
- **التحقق الحقيقي:** يومان أو ثلاثة على المجسّم الحقيقي بعد التدريب.
